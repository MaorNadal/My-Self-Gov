# ממשל אישי

מערכת לניהול חיים כממשלה: הבטחות חודשיות, תיקים, סוגיות, ציון וסגירת חודש. הפירוט המלא ב-[SPEC.md](SPEC.md).

## הרצה מקומית
פתח את `index.html` בדפדפן, או הרץ שרת מקומי בתיקייה (למשל `python -m http.server`). שים לב: קוד הגישה והצפנה דורשים הקשר מאובטח (`https` או `localhost`), ולכן עדיף שרת מקומי על פתיחת קובץ ישירות.

## פריסה ל-GitHub Pages
**חשוב:** בכל עדכון מעלים את **כל** הקבצים מהזיפ יחד (במיוחד `gov-core.js`). אם הועלה רק חלק, או שהדפדפן שומר גרסה ישנה, תופיע שורה אדומה בראש הדף. אחרי העלאה: המתן 1-2 דקות ורענן בלי מטמון (במחשב Ctrl+Shift+R; באנדרואיד: נקה "מטמון" בלבד בהגדרות האתר, לא "נתוני אתר", כי זה ימחק את הנתונים).
1. צור repo, והעלה את כל הקבצים **חוץ מ-`Code.gs`** (אפשר להעלות גם אותו, הוא לא סודי).
2. Settings ← Pages ← Source: `main` / root.
3. **אל תעלה ל-repo קובצי גיבוי של הנתונים** (`gov_backup_*.json`).

## שמירה קבועה בענן (Google Apps Script)
1. היכנס ל-[script.google.com](https://script.google.com) ← New project, והדבק את תוכן `Code.gs`.
2. בעורך הרץ את הפונקציה `setupToken` פעם אחת (אשר הרשאות), פתח View ← Logs והעתק את `GOV_TOKEN`. זה המפתח הסודי שלך.
3. Deploy ← New deployment ← Web app. Execute as: **Me**. Who has access: **Anyone**. העתק את הכתובת (נגמרת ב-`/exec`).
4. בלוח הבקרה, בכרטיס "שמירה קבועה בענן", הדבק כתובת ומפתח, לחץ "שמור ובדוק חיבור".
5. זהו. מעכשיו הסנכרון **אוטומטי לגמרי**: כל שינוי עולה לענן אחרי 3 שניות, והמכשיר מושך שינויים ממכשירים אחרים בפתיחה, בחזרה לחלון, בחזרת חיבור וכל 30 שניות. אין יותר "דחוף" ו"משוך". במכשיר חדש שבענן כבר יש בו נתונים תופיע בחירה חד-פעמית (מומלץ: "משוך מהענן").
6. **שדרוג מגרסה קודמת (v0.22):** הדבק מחדש את `Code.gs` בעורך, ואז Deploy ← Manage deployments ← Edit ← Version: New version ← Deploy. הכתובת נשארת זהה והנתונים נשמרים.

הנתונים נשמרים בקובץ `gov_data.json` בדרייב שלך (ועד 5 גיבויים מתחלפים, לכל היותר אחד בשעה, ועוד עותק יומי ל-7 הימים האחרונים). לאחר שינוי ב-`Code.gs` יש לפרוס גרסה חדשה (Manage deployments ← Edit ← New version).

**אבטחה:** הכתובת פתוחה, והמפתח הוא ההגנה היחידה. השתמש במפתח הארוך שיוצר `setupToken`, ואל תשתף אותו. הקובץ בדרייב אינו מוצפן (הצפנת הנתונים מתוכננת, ראה SPEC.md סעיף 10); המפתחות עצמם מוצפנים בכספת בדפדפן.


## אבטחה: כספת מפתחות וסיסמה (v0.6)
- **סיסמה:** בלוח הבקרה ← הגדרות ← קבע סיסמה (8+ תווים). היא גם נועלת את האתר וגם מצפינה את "הכספת".
- **הכספת** שומרת רק מוצפנים (AES-GCM-256) את כתובת ה-Apps Script, מפתח הענן ומפתח Gemini. אחרי ההזנה הם **לא מוצגים שוב** (רק כתובת מוסתרת ו-••••••••), לא מיוצאים בגיבוי ולא מסונכרנים. נעילה אוטומטית אחרי 15 דקות חוסר פעילות, או ידנית.
- **מגבלה כנה:** כל עוד האתר פתוח ופתוח בסיסמה, הקוד שלו חייב להשתמש במפתחות, ולכן מי שיושב מול הדפדפן הפתוח ומריץ קוד בקונסולה יכול לגרום לו להשתמש בהם. ההגנה היא נגד דפדפן סגור/נעול, העתקת האחסון והגיבויים. נעל כשאתה קם.
- שדרוג מגרסה קודמת: בהתחברות הראשונה אחרי השדרוג המפתחות הגלויים ישנים עוברים לכספת ונמחקים.
- אם שכחת את הסיסמה אין שחזור למפתחות: מזינים אותם מחדש (הנתונים עצמם בענן/בגיבוי).

## חיבור מכשיר נוסף (קישור מוצפן)
1. במכשיר הראשון: בלוח הבקרה, בכרטיס הענן, שמור כתובת ומפתח, ופתח "חיבור מכשיר נוסף". הזן את סיסמת הכניסה שלך ולחץ ליצירת קישור.
2. העבר את הקישור למכשיר החדש (הודעה לעצמך, מייל וכו'). **אל תעלה אותו ל-GitHub ואל תפרסם אותו**.
3. במכשיר החדש: פתח את הקישור, הזן את הסיסמה. המערכת מפענחת, קובעת אותה כסיסמת כניסה, יוצרת כספת, מתחברת לענן, מושכת את הנתונים ומוחקת את הקישור מסרגל הכתובת.

**למה לא קובץ באתר?** גם אם ה-repo פרטי, אתר GitHub Pages שלו נגיש לכל מי שיש לו הכתובת (חוץ מתוכניות ארגוניות). קובץ שמתארח באתר נשאר ציבורי. לכן הקישור מועבר ידנית, וחלק ה-`#` שבו לא נשלח לשרת.

## מה להעלות ל-GitHub
להעלות: כל קובצי האתר (`*.html`, `gov-*.js`, `Code.gs`, `README.md`, `SPEC.md`). אפשר גם `tests/` (הם לא מכילים נתונים שלך ולא נטענים באתר). **לא להעלות:** גיבויי נתונים (`gov_backup_*.json`), קישורי חיבור, מפתחות. ראה SPEC.md.

## בדיקות (אופציונלי, למפתח)
`npm i playwright` ואז `node tests/smoke.js .` ו-`node tests/gate.js .` מתוך תיקיית הפרויקט.

## חיבור Gemini
בלוח הבקרה, כרטיס "חיבור AI": הדבק מפתח API פעם אחת (או השתמש במפתח של QB Master Class אם קיים באותו דומיין). המפתח נשמר מוצפן בכספת בדפדפן הזה בלבד. מומלץ להגביל אותו ל-HTTP referrer של האתר ב-Google AI Studio.


## התקנה כאפליקציה (PWA, v0.22)
- פתח את האתר בכתובת https (GitHub Pages) בטלפון או במחשב. ב-Chrome/Edge: תפריט ← "התקן אפליקציה". באייפון (Safari): שיתוף ← "הוסף למסך הבית". בלוח הבקרה יש כרטיס "אפליקציה במכשיר" עם כפתור התקנה.
- האפליקציה נפתחת במסך מלא ועובדת גם בלי רשת (קבצי המערכת וספריות ה-CDN נשמרים במטמון אחרי הטעינה הראשונה). כשיש חיבור, הסנכרון ממשיך מעצמו.
- עדכון גרסה: מעלים את הקבצים החדשים ל-GitHub. האפליקציה מושכת אותם בפתיחה הבאה כשיש רשת (רשת קודם).
- אם מעלים גרסה חדשה, כדאי לשנות את `VERSION` בראש `sw.js` כדי לנקות מטמון ישן.
